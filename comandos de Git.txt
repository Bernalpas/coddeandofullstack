

######

Comandos para el uso de Git y GitHub

######

A.COMANDOS PARA LA CONFIGURACIÓN INICIAL DE GIT

1. Descargar Git e instalarlo. 

    https://git-scm.com/

2. Configurar mi nombre en Git

    git config --global user.name "Mi nombre"

3. Confirmar nombre de usuario con el comando:

    git config user.name            

    //Mi nombre

4. Configurar el email del usuario con el comando:

    git config --global user.email "Email del perfil de GitHub"

5. Confirmar email del usuario con el comando:

    git config user.email

    //Mi email con el que me registré en GitHub

6. Comando para listar las configuraciones de Git

    git config --list


##################################################

B. COMANDOS PARA EL USO DEL REPOSITORIO DE GIT

1. Conocer cómo está el repositorio. Lo podemos ejecutar todas las veces que querramos

    git status

2. Iniciar el seguimiento del proyecto. Sólo una vez

    git init
